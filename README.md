# Crypto AOD 개인정보 처리방침

게시 주소: https://jkinject.github.io/aod-ticker-privacy/

원본은 앱 저장소의 docs/PRIVACY.md 이며, 변경 시 index.html 을 함께 갱신합니다.

## promo.json — 프리미엄 무료 이벤트 설정

Crypto AOD 앱이 12시간마다 읽는 파일입니다. `promos` 배열에 이벤트를 추가하면 앱 업데이트 없이 "기간 한정 프리미엄 전원 무료"가 예약·시작·종료됩니다.

```json
{"promos": [
  {"id": "launch-2026-09", "start": "2026-09-16T00:00:00+09:00", "end": "2026-09-30T23:59:59+09:00"},
  {"id": "new-year-2027", "start": "2027-01-01T00:00:00+09:00", "end": "2027-01-14T23:59:59+09:00"}
]}
```

- 시각은 ISO-8601 + 시간대(`+09:00`). 앱은 진행 중인 이벤트를 우선, 없으면 다음 예정 이벤트를 저장해 시작 시각에 자동으로 켭니다.
- 이벤트를 중단하려면 해당 항목을 지우거나 `end`를 앞당깁니다. 배열을 비우면 프로모션 없음.
- 반영까지 최대 12시간(앱 실행·위젯 갱신 시 확인).
