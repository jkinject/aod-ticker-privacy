코인 시세 위젯 개인정보 처리방침

시행일: 2026-09-13

---

1. 개요

이 개인정보 처리방침은 코인 시세 위젯 앱(이하 "앱")의 사용자 데이터 처리 방식을 설명합니다.

핵심 원칙:

  • 앱은 계정이나 로그인을 요구하지 않습니다.
  • 개인정보를 수집, 저장, 또는 전송하지 않습니다.
  • 모든 데이터는 기기 내에만 저장됩니다.
  • 광고나 분석 추적이 없습니다.

---

2. 수집하는 정보

2.1 기기 내 저장 데이터

앱은 다음 정보를 사용자의 기기 내에만 저장합니다. 이 데이터는 외부로 전송되지 않습니다.

  • 관심 종목 목록: 사용자가 추가한 암호화폐 종목(예: BTC/KRW, ETH/USDT)
  • 거래소 선택: 업비트 또는 바이낸스 중 선택한 거래소
  • 갱신 주기 설정: 1분, 5분, 또는 15분 중 선택한 값
  • 최근 시세 정보: 각 종목의 가장 최근 가격, 등락률, 갱신 시각
  • 위젯 설정: 홈 화면/잠금화면 위젯 개수 및 종목별 배치

2.2 수집되지 않는 정보

앱은 다음 정보를 수집하지 않습니다.

  • 사용자 이름, 이메일 주소, 전화번호 등 개인 신원 정보
  • 주소, 직업, 나이 등 인구통계학적 정보
  • 기기 고유 식별자(IMEI, ANDROID_ID 등)
  • 위치 정보(GPS, Wi-Fi 위치)
  • 연락처, 캘린더, 사진 등 기기의 다른 앱 데이터
  • 광고 ID
  • 사용자 행동 분석 데이터(세션, 클릭, 화면 머문 시간 등)

---

3. 기기 내 저장 데이터의 관리

3.1 저장 위치

모든 기기 내 데이터는 안드로이드 시스템의 앱 전용 디렉토리에 저장되며, 다른 앱이 접근할 수 없습니다.

3.2 데이터 보관 기간

  • 관심 종목 목록 및 갱신 설정: 앱이 설치된 동안 유지
  • 최근 시세 정보: 앱이 실행되는 동안 메모리에 유지되며, 앱 종료 시 마지막 값만 저장
  • 앱을 삭제하면 모든 데이터는 함께 삭제됩니다.

3.3 데이터 암호화

앱은 개인정보를 수집하거나 저장하지 않으므로 추가 암호화 처리를 하지 않습니다. 기기의 기본 파일 시스템 보안에 의존합니다.

3.4 데이터 초기화

사용자가 원할 경우 앱 설정에서 "데이터 초기화" 기능을 통해 수동으로 모든 기기 내 저장 데이터를 삭제할 수 있습니다.

4. 외부 API 호출 및 IP 주소 전달

4.1 언제 외부로 데이터가 나가나요?

앱은 시세 정보를 조회할 때만 다음 서버에 요청을 전송합니다. 이 과정에서 기기의 IP 주소가 각 서버의 로그에 기록될 수 있습니다.

4.2 Upbit (업비트) API

서비스: 한국 암호화폐 거래소 시세 조회

요청 내용:

  • 종목 마켓 코드 (예: KRW-BTC, KRW-ETH)

요청 대상: https://api.upbit.com

응답 정보:

  • 현재 가격
  • 등락률
  • 거래 시간

IP 주소 전달: 예 (업비트 서버 로그에 기록될 수 있음)

Upbit 개인정보 정책: https://upbit.com/ 참고

4.3 Binance (바이낸스) API

서비스: 글로벌 암호화폐 거래소 시세 조회

요청 내용:

  • 종목 마켓 코드 (예: BTCUSDT, ETHUSDT)

요청 대상: https://api.binance.com

응답 정보:

  • 현재 가격 (USDT 기준)
  • 등락률
  • 거래 시간

IP 주소 전달: 예 (바이낸스 서버 로그에 기록될 수 있음)

Binance 개인정보 정책: https://www.binance.com/en/privacy 참고

4.4 CoinCap CDN (로고 이미지)

서비스: 암호화폐 코인 로고 이미지 조회

요청 내용:

  • 코인 심볼 (예: bitcoin, ethereum)

요청 대상: https://assets.coincap.io

응답 정보:

  • PNG 형식의 로고 이미지

IP 주소 전달: 예 (CoinCap 서버 로그에 기록될 수 있음)

CoinCap 서비스: ShapeShift의 무료 데이터 서비스

4.5 기타 정보

  • 위 요청에는 사용자 개인정보(이름, 이메일 등)가 포함되지 않습니다.
  • IP 주소 이외의 장치 고유 식별자는 전송되지 않습니다.
  • 업비트, 바이낸스, CoinCap의 개인정보 정책 및 로그 보관 정책은 각 서비스의 공식 페이지를 참고하세요.

5. 권한 설명

앱이 요청하는 각 안드로이드 권한의 사용 목적:

5.1 INTERNET (인터넷 접근)

용도: 업비트, 바이낸스, CoinCap 서버와 통신하여 암호화폐 시세 정보를 조회합니다.

필수성: 예

5.2 ACCESS_NETWORK_STATE (네트워크 상태 확인)

용도: 현재 네트워크 연결 상태(Wi-Fi, 모바일 데이터)를 확인하여 시세 조회 가능 여부를 판단합니다.

필수성: 예

5.3 SCHEDULE_EXACT_ALARM (정확한 알람 예약)

용도: 사용자가 선택한 1분 또는 5분 주기로 정확한 시각에 시세를 갱신하기 위해 사용합니다.

필수성: 선택적 (15분 주기 선택 시 불필요)

5.4 USE_EXACT_ALARM (정확한 알람 사용)

용도: 정확한 알람 기능을 지원하는 안드로이드 기기에서 시스템 알람을 활용합니다.

필수성: 선택적

5.5 REQUEST_IGNORE_BATTERY_OPTIMIZATIONS (배터리 최적화 제외)

용도: 화면이 꺼진 상태(Doze, 갈림길 모드)에서도 1분/5분 주기의 시세 갱신이 지속되도록 합니다.

필수성: 선택적 (1분/5분 주기 선택 시 권장, 15분 주기에서는 불필요)

5.6 WAKE_LOCK (화면 잠금 해제 상태 유지)

용도: 시세 갱신 중 기기가 절전 상태로 진입하지 않도록 짧은 시간(수초) 유지합니다.

필수성: 선택적

5.7 RECEIVE_BOOT_COMPLETED (부팅 완료 수신)

용도: 기기가 재부팅된 후 예약된 시세 갱신 스케줄을 자동으로 복원합니다.

필수성: 선택적

6. 광고 및 분석 추적

6.1 광고

이 앱에는 광고가 없습니다. 광고를 표시하거나 광고 네트워크에 연결되지 않습니다.

6.2 Google 광고 ID

이 앱은 Google 광고 ID를 사용하지 않습니다. 광고 추적 목적의 사용자 프로파일링이 없습니다.

6.3 분석 및 성능 모니터링

이 앱은 다음을 사용하지 않습니다.

  • Google Analytics
  • Firebase Analytics
  • Crashlytics 또는 기타 크래시 리포팅 서비스
  • Amplitude, Mixpanel 등 제3자 분석 도구

예외: 기기 내에서 발생한 오류 로그는 앱 메모리에만 기록되며, 외부로 전송되지 않습니다.

---

7. 아동을 대상으로 하지 않음

이 앱은 아동(13세 미만)을 대상으로 설계되지 않았습니다.

  • 암호화폐 거래 및 투자 정보를 포함합니다.
  • 아동을 대상으로 한 특별한 개인정보 보호 조치를 하지 않습니다.
  • 보호자는 아동이 이 앱을 사용하는 경우 모니터링할 책임이 있습니다.

각 서비스의 개인정보 정책은 해당 웹사이트를 방문하여 확인하세요.

9. 보안

9.1 데이터 보호 조치

  • 앱은 개인정보를 저장하지 않으므로, 개인정보 유출의 위험이 최소입니다.
  • 모든 기기 내 저장 데이터는 안드로이드 시스템의 앱 샌드박스에 의해 보호됩니다.
  • 외부 API 호출은 HTTPS를 사용하여 암호화된 통신을 합니다.

9.2 알려진 제한사항

  • 이 앱은 기기 내 저장 데이터에 대한 추가 암호화를 제공하지 않습니다.
  • 기기가 루팅된 경우 시스템 보안이 약화될 수 있습니다.
  • 공용 Wi-Fi 사용 시 IP 주소가 노출될 수 있습니다.

10. 사용자 권리 및 데이터 삭제

10.1 정보 접근 및 수정

앱이 개인정보를 수집하지 않으므로, 접근 또는 수정 요청이 해당되지 않습니다.

10.2 데이터 삭제

사용자는 언제든지 다음 방법으로 모든 기기 내 저장 데이터를 삭제할 수 있습니다.

방법 1: 앱 내 삭제

  • 앱 설정 메뉴 → "데이터 초기화" 버튼 클릭

방법 2: 시스템 설정을 통한 삭제

  • 설정 → 앱 → 코인 시세 위젯 → 저장공간 → "캐시 삭제" 또는 "데이터 삭제"

방법 3: 앱 제거

  • 코인 시세 위젯 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.

10.3 삭제 요청에 대한 응답

앱이 개인정보를 수집하지 않으므로, 별도의 삭제 요청 처리가 필요하지 않습니다.

11. 이 정책의 변경

앱의 기능이 변경되거나 새로운 권한이 추가되는 경우, 이 개인정보 처리방침을 업데이트할 수 있습니다.

11.1 변경 공지 방법

  • 앱 업데이트 시: "What's New" 섹션에 주요 변경 사항 고지
  • 주요 변경 시: Google Play Store 설명에 공지
  • 이 문서: GitHub 저장소 또는 앱 정보 페이지에서 최신 버전 제공

11.2 변경의 효력

  • 정책 변경은 공지 후 즉시 효력이 발생합니다.
  • 변경된 정책에 동의하지 않는 경우 앱 사용을 중단할 수 있습니다.
